# Animation Evaluator Family Findings

This report records the current read-only IDA evidence for why the viewer must not treat every decoded shared-animation row as one universal format. Static mesh rendering is solved enough for browsing; clean playback still depends on selecting the same cooked evaluator family that the game selects for each target.

## Implementation Boundary

- `CONFIRMED`: static meshes/textures can remain the default viewer path.
- `CONFIRMED`: raw descriptor-row keyframe exports are useful diagnostics.
- `CONFIRMED`: engine playback uses cooked evaluator families and virtual dispatch, not one universal raw row format.
- `CONFIRMED`: cooked runtime descriptors have `0x18` stride and a selector byte at `+0x10`.
- `NOT YET KNOWN`: which evaluator family `head_ctrl-node-rotation`, `Lwing_bone01-node-rotation`, or any specific Gorilla target receives at runtime.
- `NOT SAFE YET`: making skinned live playback the default GUI mode.
